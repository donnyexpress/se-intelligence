# Applied Ideation Methodology Selector Tool

## TL;DR

This session presents an Excel-based tool designed to allow engineers to select the most appropriate/likely useful tools for ideation. The tool involves having the user input importances of seven selection criteria, and from that input, it recommends the top five ideation tools (out of 13 currently included in the tool) for their situation. Embedded in the tool are pocket guides to the included ideation tools.
