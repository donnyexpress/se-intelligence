**Status**: proposed, awaiting ship approval
**Date**: 2026-08-06
**Author**: Mavis (compiled from user request)

## Impact

Three-level taxonomy; 6 new topics; 3 new sources; sidebar order changed.

## Plan

Promote the 6 engineering specialties (currently buried in `topics/eng-domains.md` as a bullet list) to a top-level rail that renders *before* the SEBoK Part 1–9 rail. The specialties are the disciplines a practitioner consults first; the SEBoK Parts are the structural backbone a learner reads first. Putting the disciplines first matches the order in which practitioners actually navigate the knowledge base.

## Why this is v1.3 and not a v1.2 patch

Taxonomy change touches:
- `assets/config.js` (new `specialtyTopics` block — affects every render that uses config)
- `assets/app.js` (sidebar and topics index — affects every page load)
- `assets/parser.js` (new key list)
- `assets/topics-index.js` (27 keys vs 21)
- 6 new topic files (~6KB each)
- 3 new source files (~3KB each)
- 1 modified existing topic (`eng-domains.md` — added cross-link block)
- Sitemap + smoke test updates

That's a structural change to the data model, not content-only. It deserves its own version bump.
