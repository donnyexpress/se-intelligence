# Logical Architecture Optimization via a Markov chain based Hierarchical Clustering Method

## TL;DR

We propose a variant of an existing approach originally proposed for the multi-agent reformulation of a MILP with a sparse constraint matrix. The goal is to address the optimization of the logical architecture by treating the Design Structure Matrix as the constraint matrix of a MILP. The method manipulates the DSM to possibly find its hidden block-diagonal structure with single or double border which allows to obtain a modular architecture by minimizing the interfaces across modules.
