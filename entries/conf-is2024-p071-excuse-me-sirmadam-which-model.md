# Excuse me Sir/Madam, which Model?

## TL;DR

Transitioning to large scale MBSE is an industry-wide challenge, not the least for the multitude of models that will be managed. This paper presents a model structure and classification scheme adapted for iterative systems development. Examples illustrating real world applications are provided. Biography John R. Palmer (The Boeing Company) - john.r.palmer2@boeing.com
