# Systems Engineering Capability Development using the “Green and Blue Track Approach”

## TL;DR

How to build a lasting SE capability? This presentation describes an approach that is: systemic, recognizing that an enterprise SE capability is built up by a balanced set of Governance, Organisation, Processes, Information and Tools; systematic, providing a strategic direction for the enterprise capability (Green Track); and pragmatic, prioritizing building the capability incrementally supporting needs of ongoing projects (Blue Track). A case is presented along with lessons learned.

## Why it matters

This presentation was delivered at the 34th Annual INCOSE International Symposium (IS 2024) in Dublin, Ireland, July 2–6, 2024. Authors: Tom Strandberg (CAG Syntell AB) - tom.strandberg@syntell.se; Jonas Larsson (CAG Syntell AB) - jonas.larsson@cag.se; Kanika Garg (CAG Syntell AB) - kanika.garg@cag.se.
