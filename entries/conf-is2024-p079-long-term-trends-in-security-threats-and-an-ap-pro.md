# Long Term Trends in Security Threats and an Ap-proach for Integrating Them into System Architecture and Design

## TL;DR

Cyber security is an evolving consideration for design of current and future systems. A literature review of cyber challenges across a range of industries reveals a set of recurring long-term trends. These trends suggest challenges to security capabilities in the future. In this paper, we summarize and analyze these trends and propose an approach for addressing them using modern methods in architecture and design activities.

## Why it matters

This paper was presented at the 34th Annual INCOSE International Symposium (IS 2024) in Dublin, Ireland, July 2–6, 2024. Authors: Larri Rosser (Raytheon Technologies) - larri_rosser@raytheon.com.
